# 📋 Exemplos de Uso do SELIX

Esta pasta contém exemplos práticos de como o SELIX pode ser utilizado por diferentes stakeholders.

## 📂 Estrutura

| Pasta | Público | Descrição |
|-------|---------|-----------|
| `copom/` | Banco Central, formuladores de política | Relatórios, cenários, comunicação |
| `ecossistema/` | Desenvolvedores, integradores | APIs, bots, dashboards |
| `academia/` | Pesquisadores, estudantes | Análises, papers, validação |
| `empresas/` | CFOs, tesourarias | Planejamento financeiro, captação |

## 🚀 Como usar

Cada pasta contém:
- Scripts prontos para execução
- Notebooks Jupyter com análises
- Exemplos de integração com APIs
- Documentação específica

## 📊 Exemplo rápido

```bash
# Relatório para o COPOM
python exemplos/copom/relatorio_copom.py

# Dashboard do ecossistema
python exemplos/ecossistema/dashboard.py
```
